Excel у тебя на итальянском -> в формулах ";" и итальянские функции.
Каждая формула дана в двух вариантах: IT (вставлять) и EN (для понимания).

Словарь:
VLOOKUP = CERCA.VERT     SUMIFS = SOMMA.PIÙ.SE     IFERROR = SE.ERRORE
INDEX   = INDICE         MATCH  = CONFRONTA        XLOOKUP = CERCA.X
IF      = SE             ABS    = ASS              FALSE   = FALSO
ROUND   = ARROTONDA      TRIM   = ANNULLA.SPAZI


---------------------------------------------------------------------
ШАГ 0. РАЗВЕДКА (10 минут, без этого формулы не заработают)
---------------------------------------------------------------------
Данные CP-CoRE (YE25 и Fcst26) должны лежать в одном из листов:
"Input -->" (и листы после него) или "7.4 Data Export".

1. Ctrl+F по всей книге (Opzioni -> Cerca in: Cartella di lavoro):
   ищи  SII_OFM_CPGEN_L_VNP_PVFP_GRS
2. Запиши:
   [ ] Лист, где нашёлся код:                 ______________
   [ ] Колонка с кодами:                       ______________
   [ ] Колонка Actual 2025 (YE25):             ______________ (это 3-я колонка таблицы?)
   [ ] Колонка Forecast 2026:                  ______________ (это 4-я колонка таблицы?)
   [ ] Есть колонка с компанией (entity)?      да / нет
   [ ] Код встречается 1 раз или много раз?    1 / много

Цифры 3 и 4 в строке 2 над колонками F и G = почти наверняка номер
колонки для CERCA.VERT. Если код в 1-й колонке таблицы, а YE25/Fcst26
в 3-й и 4-й -> гипотеза подтверждена -> ВАРИАНТ A.

Выбор варианта:
- код в 1-й колонке, 1 раз           -> ВАРИАНТ A (CERCA.VERT)
- код НЕ в 1-й колонке, 1 раз        -> ВАРИАНТ B (INDICE/CONFRONTA)
- код много раз (по компаниям)       -> ВАРИАНТ C (SOMMA.PIÙ.SE с entity)

Ниже <SRC> = имя листа-источника, напр. 'Input CP-CoRE'
(с апострофами, если в названии пробел).

Строка | C (код)                         | E (название)                       | Тип
-------+---------------------------------+------------------------------------+------------
2      |                                 |                                    | F2=3, G2=4 (индексы колонок)
7      |                                 | Own Funds Capital Generation       | заголовок

Проверь номера строк у себя - если сдвинуты, поменяй номера в формулах.

Колонки:
F = Actual 2025    <- CP-CoRE (индекс 3)
G = Forecast 2026  <- CP-CoRE (индекс 4)
H = Actual 2026    <- из J (вставка Tagetik) x масштаб K5

K5 = Reporting scale (1 = файл в единицах, 1000 = в тысячах)


---------------------------------------------------------------------
ШАГ 2. ФОРМУЛЫ СТРОК С ДАННЫМИ (F9, затем протянуть)
---------------------------------------------------------------------

ВАРИАНТ A - CERCA.VERT по индексу из строки 2
IT:  =SE.ERRORE(CERCA.VERT($C9;<SRC>!$A:$Z;F$2;FALSO);0)
EN:  =IFERROR(VLOOKUP($C9;<SRC>!$A:$Z;F$2;FALSE);0)
     $A:$Z -> поставь реальный диапазон, первая колонка = колонка кодов.
     F$2 -> берёт 3 для F и 4 для G автоматически при протягивании вправо.

ВАРИАНТ B - INDICE/CONFRONTA (код не в первой колонке)
IT:  =SE.ERRORE(INDICE(<SRC>!$A:$Z;CONFRONTA($C9;<SRC>!$B:$B;0);F$2);0)
EN:  =IFERROR(INDEX(<SRC>!$A:$Z;MATCH($C9;<SRC>!$B:$B;0);F$2);0)
     $B:$B -> колонка кодов; F$2 = номер колонки внутри $A:$Z.

ВАРИАНТ C - SOMMA.PIÙ.SE с компанией
IT:  =SOMMA.PIÙ.SE(<SRC>!$E:$E;<SRC>!$B:$B;$C9;<SRC>!$A:$A;Entity)
EN:  =SUMIFS(<SRC>!$E:$E;<SRC>!$B:$B;$C9;<SRC>!$A:$A;Entity)
     $E:$E = колонка значений YE25 (для G - колонка Fcst26)
     $B:$B = коды, $A:$A = компании
     Entity = ячейка с выбранной компанией (проверь лист Index -
     там может быть селектор компании; иначе создай ячейку сама)

Куда вставить:
F9  -> формула, протянуть на G9
Скопировать F9:G9 -> F10:G10, F12:G12, F13:G13
(НЕ вставлять в строку 11 - она пустая разделительная)


---------------------------------------------------------------------
ШАГ 3. ПОДЫТОГ И ACTUAL 2026
---------------------------------------------------------------------
Подытог Life SII VNP:
F8:  =F9+F10          протянуть на G8, H8
J8:  =J9+J10          (подытог и в зоне вставки)

Actual 2026 (колонка H) из зоны вставки J:
H9:  =J9*$K$5         протянуть на H10, H12, H13
     (J = значения из OF_AOM, K5 = масштаб; если OF_AOM в тысячах,
     в K5 ставится 1000 и H будет в единицах, как F и G)

Если H должна оставаться пустой, пока данные не вставлены:
IT:  =SE(J9="";"";J9*$K$5)
EN:  =IF(J9="";"";J9*$K$5)

ШАГ 4. КОЛОНКИ ОТКЛОНЕНИЙ (то, что делает это "performance review")
---------------------------------------------------------------------
Свободные колонки справа, напр. L и M (строки 7-13, под жёлтым боксом).
L7: "Δ Act26 vs Fcst26"     M7: "Δ %"

L8:  =H8-G8
M8:
IT:  =SE.ERRORE((H8-G8)/ASS(G8);"")
EN:  =IFERROR((H8-G8)/ABS(G8);"")
Протянуть на строки 9, 10, 12, 13. Формат M: процент.
ASS (ABS) - чтобы знак был правильным, когда план отрицательный
(например NBV Risk Margin).

Опционально, YoY: N7 "Δ Act26 vs Act25"   N8: =H8-F8

ШАГ 5. КОНТРОЛИ
---------------------------------------------------------------------
Колонка O "Check" (или справа от Δ):

[1] Подытог = сумма деталей (защита от сломанной формулы)
    O8:  =ARROTONDA(F8-(F9+F10);0)=0        EN: =ROUND(F8-(F9+F10);0)=0
    -> VERO/FALSO (TRUE/FALSE)

[2] Код найден в источнике (ловит опечатки и обрезанные коды)
    IT:  =SE(VAL.NON.DISP(CONFRONTA($C9;<SRC>!$B:$B;0));"CODE MISSING";"ok")
    EN:  =IF(ISNA(MATCH($C9;<SRC>!$B:$B;0));"CODE MISSING";"ok")
    Важно: SE.ERRORE в шаге 2 тихо даёт 0, если код не найден -
    без этой проверки "0" и "нет кода" выглядят одинаково.

[3] Зона Tagetik заполнена
    IT:  =SE(CONTA.VALORI(J9:J13)=0;"J EMPTY - paste OF_AOM";"ok")
    EN:  =IF(COUNTA(J9:J13)=0;"J EMPTY - paste OF_AOM";"ok")

[4] Сверка с AoM (когда добавишь блок AoM ниже, см. шаг 7):
    Life SII VNP микротаблицы = строка Life SII VNP в блоке
    Normalised Capital Generation  -> разница = 0

ШАГ 8. ТЕКСТ ДЛЯ РАСШИРЕННОГО БОКСА-ИНСТРУКЦИИ (вставить в лист)
---------------------------------------------------------------------
HOW THIS SHEET WORKS
1. Actual 2025 and Forecast 2026 (cols F-G) are fed automatically
   from CP-CoRE via Account Code (col C). Column index in row 2.
   Do not overwrite.
2. Actual 2026: download "OF_AOM - Official output - OF Analysis of
   Movement" from Tagetik, sheet "2.0 OF AoM", paste values in col J.
   Set the file scale in K5 (1 = units, 1000 = thousands).
   Col H converts automatically (J x K5).
3. Subtotals (bold rows) are formulas - do not type values.
4. Check columns must show TRUE / "ok". "CODE MISSING" = Account Code
   not found in CP-CoRE export.
5. Variance columns compare Actual 2026 vs Forecast 2026.
